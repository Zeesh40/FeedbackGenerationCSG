# FeedbackGenerationCSG

This Dissertation project is a rule-based feedback generation tool designed to support teachers and educators in creating personalised and grammatically accurate feedback for students, by following a context sensitive grammar designed by myself.

The system allows teachers to:
- Input multiple assessment criteria with corresponding percentage scores.
- Add optional justifications to explain decisions.
- Choose how feedback is ordered and structured (e.g. strengths first, weaknesses first).
- Generate feedback that is clear and varied.

Technologies Used:

Frontend:
- HTML & CSS
- JavaScript
- SweetAlert2

Backend:
- Python (Flask)
- spaCy (Natural Language Processing)
